Solmar City is a sun-soaked open-world crime game: explore a coastal city on foot and by car, steal vehicles, outrun the police, and work off a debt across 8 story missions. Built with three.js for make.fun's "Make GTA 6" bounty.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
